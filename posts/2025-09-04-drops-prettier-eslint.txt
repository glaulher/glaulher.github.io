<h2>📌 Como configurar ESLint + Prettier no Vite com React e TypeScript</h2>
<p>Se você está começando um projeto com Vite + React + TypeScript, manter o código limpo e consistente é essencial. Nesse post, vamos configurar ESLint e Prettier juntos, explicando cada plugin e como ele ajuda a manter a qualidade do seu código.</p>
<hr>
<h2>1️⃣ Instale as dependências</h2>
<pre><code class="language-bash">
npm install --save-dev eslint prettier @eslint/eslintrc \
@typescript-eslint/parser @typescript-eslint/eslint-plugin \
eslint-plugin-react eslint-plugin-react-hooks eslint-plugin-jsx-a11y \
eslint-plugin-import eslint-plugin-prettier

</code></pre>
<hr>
<h2>2️⃣ Crie o arquivo eslint.config.mjs no root do projeto</h2>
<pre><code class="language-bash">
import { dirname } from 'path';
import { fileURLToPath } from 'url';
import { FlatCompat } from '@eslint/eslintrc';

const __filename = fileURLToPath(import.meta.url);
const __dirname = dirname(__filename);

const compat = new FlatCompat({
  baseDirectory: __dirname,
  recommendedConfig: { rules: {} }, // necessário para versões recentes
});

const eslintConfig = [
  ...compat.config({
    extends: [
      'eslint:recommended',                  // Regras recomendadas do ESLint
      'plugin:react/recommended',            // Regras para React
      'plugin:react-hooks/recommended',      // Regras para Hooks do React
      'plugin:@typescript-eslint/recommended', // Regras para TypeScript
      'plugin:jsx-a11y/recommended',         // Regras de acessibilidade
      'plugin:import/errors',                // Regras para import/export
      'plugin:import/warnings',
      'plugin:prettier/recommended',         // Integra ESLint + Prettier
    ],
    plugins: [
      'react',
      'react-hooks',
      '@typescript-eslint',
      'jsx-a11y',
      'import',
      'prettier',
    ],
    rules: {
      'react/react-in-jsx-scope': 'off',         // React 17+ não precisa importar React
      'react/prop-types': 'off',                 // TS já faz tipagem
      '@typescript-eslint/explicit-function-return-type': 'off',
      'prettier/prettier': [
        'error',
        {
          trailingComma: 'all',
          printWidth: 80,
          tabWidth: 2,
          arrowParens: 'always',
          singleQuote: true,
          semi: true,
          endOfLine: 'auto',
        },
      ],
    },
  }),
];

export default eslintConfig;

</code></pre>
<h2>3️⃣ O que cada plugin faz</h2>
<p>| Plugin/Extend                           | Função                                                                                                   |
|----------------------------------------|--------------------------------------------------------------------------------------------------------|
| <code>eslint:recommended</code>                    | Ativa as regras recomendadas do ESLint, como evitar variáveis não usadas, uso correto de operadores, etc. |
| <code>plugin:react/recommended</code>              | Fornece regras específicas para React, garantindo boas práticas em componentes, props e JSX.            |
| <code>plugin:react-hooks/recommended</code>        | Garante o uso correto dos Hooks do React, evitando erros comuns como dependências faltando no <code>useEffect</code>. |
| <code>plugin:@typescript-eslint/recommended</code>| Adiciona regras específicas do TypeScript, como tipagem correta de funções e variáveis.                 |
| <code>plugin:jsx-a11y/recommended</code>           | Ajuda a tornar seu app acessível, como adicionar labels em formulários e textos alternativos em imagens.|
| <code>plugin:import/errors</code> + <code>plugin:import/warnings</code> | Evita problemas em importações e exportações, como arquivos faltando ou importações duplicadas.        |
| <code>plugin:prettier/recommended</code>           | Integra o Prettier ao ESLint, permitindo que regras de formatação sejam aplicadas automaticamente.      |</p>
<h2>4️⃣ Configuração do editor</h2>
<p>tenha os plugins prettier e eslint instalados no editor para o funcionamento da configuração</p>
<p>Exemplo de configuração no settings do vscode:</p>
<pre><code class="language-json">{
  {   
    //copie sem os comentário para não dar erro no json
    
    // Formata automaticamente ao salvar
    "editor.formatOnSave": true,
    
    // ESLint vai validar esses tipos de arquivos
    "eslint.validate": [
      "javascript",
      "javascriptreact",
      "typescript",
      "typescriptreact"
    ],

    // Aplica ESLint fix automaticamente ao salvar para todos os tipos de arquivo do projeto
     
    "[javascript, javascriptreact, typescript, typescriptreact]": {
      "editor.codeActionsOnSave": {
        "source.fixAll.eslint": "explicit"
      },
      // Define o Prettier como o formatador padrão
      "editor.defaultFormatter": "esbenp.prettier-vscode",
    },   
  }
}

</code></pre>

<p>Com essa configuração, seu projeto Vite + React + TypeScript fica pronto para desenvolvimento, mantendo código limpo, consistente e acessível.</p>
