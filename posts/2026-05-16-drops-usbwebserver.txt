<h2>🖥️ Como atualizar USBWebserver com Apache 2.4.67, PHP 8.5.6 e MariaDB 11.4.10</h2>
<p>O USBWebserver é uma solução portátil excelente para desenvolvimento local. Recentemente atualizei todas as ferramentas para as versões mais recentes e troquei o MySQL pelo MariaDB. Neste post mostro o passo a passo completo.</p>
<hr>
<h2>✅ Versões utilizadas</h2>
<ul>
<li><strong>Apache 2.4.67</strong> (Win64) — Apache Lounge VS18</li>
<li><strong>PHP 8.5.6</strong> (ZTS Visual C++ 2022 x64)</li>
<li><strong>MariaDB 11.4.10</strong> (substitui o MySQL)</li>
<li><strong>phpMyAdmin 5.2.3</strong></li>
</ul>
<hr>
<h2>1️⃣ Faça backup de tudo</h2>
<p>Antes de começar, copie toda a pasta do USBWebserver para um local seguro:</p>
<pre><code class="language-bash"># Crie uma cópia de segurança
xcopy C:\USBWebserver C:\USBWebserver_backup /E /I
</code></pre>
<p>Os arquivos de configuração originais ficam em <code>settings/</code>:</p>
<ul>
<li><code>httpd.conf</code> — configuração do Apache</li>
<li><code>php.ini</code> — configuração do PHP</li>
<li><code>my.ini</code> — configuração do MariaDB/MySQL</li>
<li><code>usbwebserver.ini</code> — config geral da ferramenta</li>
</ul>
<hr>
<h2>2️⃣ Baixe as versões mais recentes</h2>
<h3>Apache 2.4.67</h3>
<p>Acesse o <a href="https://www.apachelounge.com/download/">Apache Lounge</a> e baixe o pacote <code>httpd-2.4.67-win64-VS18.zip</code>.</p>
<h3>PHP 8.5.6</h3>
<p>Acesse <a href="https://windows.php.net/download/">windows.php.net</a> e baixe o <strong>Thread Safe (ZTS)</strong> x64:</p>
<pre><code class="language-bash"># Link direto (exemplo)
https://windows.php.net/downloads/releases/php-8.5.6-Win32-vs17-x64.zip
</code></pre>
<h3>MariaDB 11.4.10</h3>
<p>Acesse <a href="https://mariadb.org/download/">mariadb.org/download</a> e baixe o ZIP para Windows x64:</p>
<pre><code class="language-bash"># Link direto (exemplo)
https://archive.mariadb.org/mariadb-11.4.10/winx64-packages/mariadb-11.4.10-winx64.zip
</code></pre>
<hr>
<h2>3️⃣ Substituindo o Apache</h2>
<ol>
<li>Apague a pasta <code>apache2/</code> do USBWebserver</li>
<li>Extraia o conteúdo do <code>httpd-2.4.67-win64-VS18.zip</code></li>
<li><strong>Renomeie a pasta extraída para <code>apache2</code></strong> e cole no USBWebserver</li>
<li>Copie o <code>settings/httpd.conf</code> para <code>apache2/conf/httpd.conf</code></li>
<li><strong>Duplique o executável com o sufixo <code>_usbwv8</code></strong>:</li>
</ol>
<pre><code class="language-bash">copy apache2\bin\httpd.exe apache2\bin\httpd_usbwv8.exe
</code></pre>
<blockquote>
<p>⚠️ O USBWebserver inicia o Apache usando o executável <code>httpd_usbwv8.exe</code>. Sem essa cópia renomeada, o programa não consegue gerenciar o serviço.</p>
</blockquote>
<p>O <code>httpd.conf</code> do USBWebserver usa placeholders que são substituídos automaticamente:</p>
<pre><code class="language-apache">Define SRVROOT "c:/Apache24"
ServerRoot "{path}/apache2"
Listen {port}
ServerName localhost:{port}
DocumentRoot "{rootdir}"

# Configuração do PHP
LoadModule php_module "{path}/php/php8apache2_4.dll"
AddType application/x-httpd-php .php
PHPIniDir "{path}/php"
</code></pre>
<hr>
<h2>4️⃣ Substituindo o PHP</h2>
<ol>
<li>Apague a pasta <code>php/</code> do USBWebserver</li>
<li>Extraia o conteúdo do <code>php-8.5.6-Win32-vs17-x64.zip</code></li>
<li><strong>Renomeie a pasta extraída para <code>php</code></strong> e cole no USBWebserver</li>
<li>Copie o <code>settings/php.ini</code> para <code>php/php.ini</code></li>
</ol>
<blockquote>
<p>⚠️ O <code>httpd.conf</code> carrega o PHP via <code>php8apache2_4.dll</code>. O PHP 8.5.6 já fornece essa DLL com o mesmo nome, então não precisa renomear. Verifique se o arquivo <code>php/php8apache2_4.dll</code> existe.</p>
</blockquote>
<p>Verifique se o <code>php.ini</code> tem as extensões necessárias descomentadas:</p>
<pre><code class="language-ini">extension=curl
extension=gd
extension=mbstring
extension=mysqli
extension=openssl
extension=pdo_mysql
</code></pre>
<p>E o <code>extension_dir</code> apontando para o local correto:</p>
<pre><code class="language-ini">extension_dir = "{path}\php\ext\"
</code></pre>
<hr>
<h2>5️⃣ Substituindo o MySQL pelo MariaDB</h2>
<p>Essa é a etapa mais importante. O MariaDB é compatível com MySQL, então você pode usar a mesma pasta <code>mysql/</code>.</p>
<ol>
<li>Apague a pasta <code>mysql/</code> do USBWebserver</li>
<li>Extraia o <code>mariadb-11.4.10-winx64.zip</code></li>
<li><strong>Renomeie a pasta extraída para <code>mysql</code></strong> e cole no USBWebserver</li>
<li>Copie o <code>settings/my.ini</code> para <code>mysql/my.ini</code></li>
<li><strong>Garanta o <code>mysqld.exe</code> e duplique com o sufixo <code>_usbwv8</code></strong>:</li>
</ol>
<pre><code class="language-bash">REM Se mysqld.exe não existir, copie de mariadbd.exe
copy mysql\bin\mariadbd.exe mysql\bin\mysqld.exe

REM Duplique com o sufixo _usbwv8 (obrigatório)
copy mysql\bin\mysqld.exe mysql\bin\mysqld_usbwv8.exe
</code></pre>
<blockquote>
<p>⚠️ <strong>ATENÇÃO:</strong> O USBWebserver gerencia o banco usando o executável <code>mysqld_usbwv8.exe</code>.</p>
</blockquote>
<p>O <code>my.ini</code> básico:</p>
<pre><code class="language-ini">[mysqld]
port = 3306
sql_mode=NO_ENGINE_SUBSTITUTION,STRICT_TRANS_TABLES
</code></pre>
<p>O USBWebserver inicia o banco via <code>mysql\bin\mysqld_usbwv8.exe</code>, e com essa etapa o MariaDB funcionará perfeitamente.</p>
<hr>
<h2>6️⃣ Atualizando o phpMyAdmin</h2>
<ol>
<li>Apague a pasta <code>phpmyadmin/</code></li>
<li>Baixe a versão mais recente em <a href="https://www.phpmyadmin.net/downloads/">phpmyadmin.net</a></li>
<li><strong>Renomeie a pasta extraída para <code>phpmyadmin</code></strong> e cole no USBWebserver</li>
</ol>
<blockquote>
<p>⚠️ O USBWebserver espera a pasta <code>phpmyadmin/</code>. O nome dos executáveis do phpMyAdmin (arquivos PHP) não precisa ser alterado.</p>
</blockquote>
<p>O alias já está configurado no <code>httpd.conf</code>:</p>
<pre><code class="language-apache">Alias /phpmyadmin "{path}/phpmyadmin/"
</code></pre>
<hr>
<h2>7️⃣ Verificando as configurações</h2>
<h3>usbwebserver.ini</h3>
<pre><code class="language-ini">[apache]
port=80
[mysql]
port=3306
[algemeen]
slocal=0
hide=0
local=0
root={path}/root
lang=Portuguese
</code></pre>
<hr>
<h2>8️⃣ Verifique os executáveis (resumo)</h2>
<p>Antes de iniciar, confira se os nomes das pastas e executáveis estão no padrão que o USBWebserver espera:</p>
<table>
<thead>
<tr>
<th>Local</th>
<th>Obrigatório</th>
<th>Como obter</th>
</tr>
</thead>

</tr>
<tr>
<td><code>apache2/bin/httpd_usbwv8.exe</code></td>
<td><strong>Gerenciamento USBWebserver</strong></td>
<td><code>copy httpd.exe httpd_usbwv8.exe</code></td>
</tr>
<tr>
<td><code>php/php8apache2_4.dll</code></td>
<td>Módulo PHP</td>
<td>Já vem no zip</td>
</tr>
<tr>
<td><code>mysql/bin/mariadbd.exe</code></td>
<td>Servidor MariaDB</td>
<td>Já vem no zip</td>
</tr>
<tr>
<td><code>mysql/bin/mysqld.exe</code></td>
<td>Compatibilidade MySQL</td>
<td><code>copy mariadbd.exe mysqld.exe</code></td>
</tr>

<td><code>mysql/bin/mysqld_usbwv8.exe</code></td>

<blockquote>
<p>⚠️ Os executáveis com sufixo <code>_usbwv8</code> são <strong>obrigatórios</strong>. O USBWebserver os utiliza para iniciar/parar os serviços. Sem eles, o programa não funciona.</p>
</blockquote>
<hr>
<h2>9️⃣ Testando o ambiente</h2>
<p>Inicie o USBWebserver e acesse:</p>
<ol>
<li><strong>Apache</strong>: <a href="http://localhost">http://localhost</a> — deve mostrar a página inicial</li>
<li><strong>PHP</strong>: crie um <code>info.php</code> na pasta <code>root/</code> com <code>&#x3C;?php phpinfo(); ?></code> e acesse</li>
<li><strong>phpMyAdmin</strong>: <a href="http://localhost/phpmyadmin">http://localhost/phpmyadmin</a></li>
<li><strong>MariaDB</strong>: Verifique a versão no phpMyAdmin ou via linha de comando:</li>
</ol>
<pre><code class="language-bash">mysql\bin\mysql.exe -V
# Saída: mysql from 11.4.10-MariaDB
</code></pre>
